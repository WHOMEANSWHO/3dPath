# 3dPath

FiveM mapping school: Blender, props, interiors, buildings, CodeWalker, and outdoor compounds. Slow/fast lesson pace, timestamped videos, written keybind steps.

## Download

**[3dPath.exe](https://github.com/WHOMEANSWHO/3dPath/releases/latest/download/3dPath.exe)** — one file, no Node. Latest [Release](https://github.com/WHOMEANSWHO/3dPath/releases/latest).

Windows SmartScreen may show **More info → Run anyway** (the app is not signed). Same as ClipKit.

Source and build notes live in [`3dpath/README.md`](3dpath/README.md).
